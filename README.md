Technology Used: Python, Tkinter, SQLite
Description:
Hospital Management System is a desktop-based application built with Python and Tkinter to automate hospital operations. It allows efficient management of patients, employees, rooms, appointments, and billing through a user-friendly GUI, while ensuring reliable data storage with SQLite.
Key Features:
Secure login authentication for authorized access.
Patient management with details like age, disease, contact, and room allocation.
Employee management for doctors and staff.
Room management with type and availability tracking.
Appointment scheduling with doctor selection by name.
Billing module to generate and manage patient bills.
Input validation for phone numbers and date formats.
CRUD operations (Add, Delete, Update) for all tables.
Achievements:
Designed a modular and maintainable code structure using Object-Oriented Programming.
Developed a GUI-based interface for intuitive navigation and smooth workflow.
Ensured data persistence and integrity using SQLite database.
